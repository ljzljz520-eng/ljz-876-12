# 在线考试题库系统（876）

## 项目类型
- 全栈 Web 项目（`frontend` + `backend`）

## 项目简介
本项目是一个基于 Vue 3 + Laravel 12 的在线考试与题库管理系统，支持多角色登录、题库管理、试卷管理、在线考试与成绩统计。

## 技术栈
### 前端
- Vue 3
- Vite
- Pinia
- Vue Router
- Axios
- TailwindCSS

### 后端
- Laravel 12（PHP 8.2）
- Laravel Sanctum（Token 鉴权）
- MySQL 8.0

### 运行方式
- Docker Compose（推荐，当前项目默认方式）

## 核心功能
1. 用户认证：注册、登录、退出。
2. 题库管理：题目增删改查、分类管理。
3. 试卷管理：试卷创建、编辑、题目关联。
4. 在线考试：开始考试、提交答卷、自动评分。
5. 成绩统计：个人成绩与管理端统计数据。
6. 题目版本锁定：发布即锁版、开考快照、成绩页版本标注、撤回影响提醒（见下）。

## 题目版本锁定机制
为保证考试公平与历史可追溯，系统对题目实行全链路版本管理：

- **题目版本（`question_versions`）**：每次修改题干、选项、正确答案或解析都会生成新版本（v1、v2……），只改难度/分值不升版；题库页可查看完整版本历史。
- **试卷发布锁定**：试卷需先"发布"学生才能看到；发布时每道题锁定到当时版本。教师之后改题不影响该试卷。
  - 正考发布后即使题目被修订，**已经开考/交卷的试卷仍使用开考当时的版本**（开考瞬间写入 `exam_record_snapshots`，判分也读快照）。
  - **补考卷**可在试卷管理中点击"重新发布"引用题目最新版本；已结束的历史考试不受影响。
- **成绩页版本标注**：成绩列表显示"最新版 / N 题用旧版"；答卷详情逐题标注"本卷使用 vX（题库最新 vY）"，题面、选项、解析、判分均按锁定版本回放。
- **撤回影响提醒**：撤回题目时系统统计并展示引用该题的试卷、已完成与进行中的历史考试（含各自使用的版本）；撤回不删除历史快照，已开考考试不受影响，撤回题不能再加入新试卷，可恢复。

> 数据库版本升级通过 Laravel 迁移自动完成（后端容器启动时执行 `php artisan migrate --force`），对存量数据会回填 v1 版本快照并把已启用试卷标记为已发布。

## 人工验证步骤（建议）
1. 打开登录页：`http://localhost:8080/login`。
2. 使用测试账号手动登录，确认菜单与角色权限一致。
3. 进入题库管理，验证新增/编辑/删除流程。
4. 进入试卷管理，验证题目关联与试卷删除流程。
5. 学生账号完成一次在线考试并查看成绩。
6. Admin 查看统计页数据。
7. API 冒烟：

```bash
docker compose exec backend sh -lc "curl -s -o /tmp/unauth.txt -w '%{http_code}\n' http://localhost:8080/api/exams"
docker compose exec backend sh -lc "curl -s -X POST http://localhost:8080/api/auth/login -H 'Content-Type: application/json' -d '{\"email\":\"admin@example.com\",\"password\":\"password\"}'"
```

预期：未登录访问受保护接口返回 `401`；登录接口返回包含 `token` 的 JSON。

## 安全与质量说明
- 密码为哈希存储（bcrypt）。
- API 使用 Sanctum Token 鉴权。
- 接口包含输入校验与错误处理。
- CORS 与基础限流已配置。
